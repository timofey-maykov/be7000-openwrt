BE7000 OpenWrt package feed

Packages built for aarch64_cortex-a73, the CPU type this firmware uses. The official OpenWrt mirror only carries aarch64_cortex-a53 for this target, so its generic feeds do not resolve here.

Add to /etc/apk/repositories.d/customfeeds.list:

https://timofey-maykov.github.io/be7000-openwrt/feed/aarch64_cortex-a73/base/packages.adb
https://timofey-maykov.github.io/be7000-openwrt/feed/aarch64_cortex-a73/packages/packages.adb
https://timofey-maykov.github.io/be7000-openwrt/feed/aarch64_cortex-a73/luci/packages.adb
https://timofey-maykov.github.io/be7000-openwrt/feed/aarch64_cortex-a73/awg/packages.adb

The indexes are signed with the same key the firmware trusts, so no extra setup is needed.
