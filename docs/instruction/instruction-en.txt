Beam WRT 1.5.4 for the Xiaomi BE7000

This is firmware based on OpenWrt with kernel 6.18. The instructions come in parts, read the one that fits your case.

1-install-en.txt
First install, the router runs the Xiaomi factory firmware now. Backup, installation and first login.

2-update-en.txt
Beam WRT is already installed and you want a newer version. If you update to 1.4 from any 1.x version, read the first section of this file before anything else. After it comes the regular update and what to do with a very old version, from 1.0 up to 1.2.2.

3-rollback-and-problems-en.txt
The router does not answer, does not boot, has no wired network, or you want to go back to the factory firmware. Going back now also works with a button on System, Slots. The file also tells how to collect a log and what to post.

4-features-en.txt
What the firmware can do. Packages, 5 GHz modes and MLO, stock settings import, slots, hardware offload, USB storage, Docker and what has been tested.


What is in the archive

openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-factory.ubi is the image for installing from stock.
install-from-stock.sh writes the image into the free slot and switches the boot to it.
install-from-openwrt.sh is for a router running another OpenWrt with the factory bootloader, see the end of 1-install-en.txt.
rollback-to-stock.sh takes the router back to the factory firmware. The System, Slots page does the same.
sha256sums.txt has the checksums.

The file for updating an installed firmware (sysupgrade.bin) is not in the archive, it is a separate download in the same release.


Never do this

Do not write anything to the bootloader partitions APPSBL and APPSBL_1. That is the only way to ruin the board for good.
The UART on the board runs at 1.8 V. Do not transmit into the console with a 3.3 V adapter.
