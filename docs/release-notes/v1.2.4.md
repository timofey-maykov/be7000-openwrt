Первый релиз, собранный целиком на GitHub Actions. Руками больше ничего не собирается, образ и фид выходят из одного прогона.

Обновиться стоит всем, кто на 1.2.3 и старше.

Что изменилось

- Служба be7000-bootconfirm в конце загрузки обнуляет счётчик попыток загрузчика и отмечает свой слот рабочим. Без неё образы до 1.2.2 уходили в сток после седьмой перезагрузки.
- Установщик со стока идёт по пути штатного обновления Xiaomi: flag_last_success остаётся на стоке, ставится flag_ota_reboot=1. Если OpenWrt не поднялась, следующее включение возвращает сток, ждать семь включений не нужно.
- bigoverlay ставит стоку flag_format_overlay=1. Раньше сток после возврата поднимался с пустым /etc/config и без SSH. Кто уже попал: на стоке nvram set restore_defaults=1 && nvram commit && reboot -f, или reset на десять секунд.
- Журнал загрузки пишется во флеш: dmesg в crash_syslog (mtd27) в начале загрузки, каждые 15 секунд первые четыре минуты и в конце, паники ядра через mtdoops в crash (mtd26). Читается со стока: dd if=/dev/mtd27 bs=64k 2>/dev/null | strings. Так можно разбираться с платами, которые не грузятся, без UART.
- Модули ядра берутся из каталога фида с хешем этого ядра, старые образы свой фид не теряют.
- В фиде появились dockerd, containerd, runc, docker, docker-compose, rclone, zerotier, dnscrypt-proxy2 и модули ядра под Docker. Команда be7000-docker setup и страницы Docker в LuCI в образе есть, но вживую на этом релизе ещё не проверялись, считайте их предварительными.
- В инструкции: шаг про пароль root в xmir-patcher, раздел про адрес компьютера, исправлено «четыре включения».

Известное. Две платы не грузят ни один нативный образ, на одной из них система виснет сразу после начала preinit. Разбирается в теме на 4PDA, для этого и появился журнал во флеше.
