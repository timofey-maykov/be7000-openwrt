Beam WRT 1.5.0. Роутеры последних партий загружаются стабильно, больше места под пакеты, быстрее загрузка.

Что изменилось

- Исправлена ошибка, из-за которой роутеры последних партий иногда не загружались после установки или перезагрузки и оставались с оранжевым индикатором.
- На странице Система, Слоты второй слот можно отдать под пакеты. Он объединяется с разделом настроек, и места для пакетов становится около 57 МБ вместо 20. Перед этим роутер сохраняет копию слота, по ней слот можно вернуть, например с заводской прошивкой.
- Сброс к заводским настройкам теперь работает и тогда, когда настройки лежат не во внутреннем разделе прошивки.
- Роутер загружается примерно на 8 секунд быстрее.
- Zapret Manager обновлён до 3.97-r2, модули Steer снова добавляются из панели.
- Напряжение процессора не опускается ниже заводского.

Обновление обычное, настройки и пакеты сохраняются.

Спасибо zerc00l за роутер для проверки и подключение UART, и всем, кто помогал в issues на GitHub.

Beam WRT 1.5.0. Routers from the latest batches boot reliably, more room for packages, faster boot.

What changed

- Fixed a bug that sometimes kept routers from the latest batches from booting after an install or a reboot, with the indicator staying orange.
- On the System, Slots page the second slot can be given over to packages. It is joined with the settings partition, and packages get about 57 MB instead of 20. Before that the router saves a copy of the slot, which brings the slot back, for example with the stock firmware.
- A reset to factory settings now also works when the settings live outside the firmware's own partition.
- The router boots about 8 seconds faster.
- Zapret Manager is updated to 3.97-r2, Steer modules can be added from the panel again.
- The CPU voltage no longer goes below the stock level.

Updating is the usual one, settings and packages are kept.

Thanks to zerc00l for a router to test on and for hooking up UART, and to everyone who helped in the GitHub issues.

Beam WRT 1.5.0。最新批次的路由器可以稳定启动，软件包空间更大，启动更快。

更新内容

- 修复了最新批次路由器在安装或重启后有时无法启动、指示灯一直保持橙色的问题。
- 在 系统 → 槽位 页面可以把第二个槽位交给软件包使用。它会与设置分区合并，软件包空间从约 20 MB 增加到约 57 MB。在此之前路由器会保存该槽位的副本，以后可以用它恢复槽位，例如恢复原厂固件。
- 当设置不在固件自身的分区中时，恢复出厂设置现在也能正常工作。
- 路由器启动快了大约 8 秒。
- Zapret Manager 已更新到 3.97-r2，又可以在面板中添加 Steer 模块了。
- 处理器电压不再低于原厂水平。

更新方法不变，设置和软件包都会保留。

感谢 zerc00l 提供用于测试的路由器并接好了 UART，也感谢所有在 GitHub issues 中提供帮助的人。
