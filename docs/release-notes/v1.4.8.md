Beam WRT 1.4.8. Роутер больше не перезагружается при сбое прошивки модуля 5 ГГц во время перенастройки MLO, появились roamd и переход с другой OpenWrt.

Что исправлено

- Если прошивка модуля 5 ГГц падала в тот момент, когда hostapd перестраивал сеть MLO с подключёнными клиентами, например после изменения настроек Wi-Fi, драйвер ath12k обращался к уже освобождённым таблицам, ядро падало и роутер перезагружался. Теперь прошивка перезапускается, а роутер продолжает работать.
- После установки пакета с новым протоколом (GRE, L2TP, 6in4 и другие) его интерфейс не поднимался, пока не перезапустить сеть: сеть узнаёт протоколы только при своём запуске. Теперь в верхней панели LuCI появляется кнопка «Перезапустить сеть» с объяснением, а apk пишет то же самое после установки.

Что нового

- На странице Сервисы, Дополнения появился roamd, бесшовный роуминг Wi-Fi: перевод клиентов с 2,4 на 5 ГГц, 802.11k/v/r и сеть из нескольких роутеров OpenWrt. Он собирается в фиде Beam WRT с двумя правками. Сеть MLO он не трогает, потому что 802.11r на ней приводил к сбою прошивки модуля 5 ГГц. Обновления приходят из фида, а не через его встроенную проверку.
- В архиве релиза появился install-from-openwrt.sh для перехода на Beam WRT с другой OpenWrt с заводским загрузчиком. Если во втором слоте заводская прошивка, он переключает загрузку на неё, ничего не стирая. Если там что-то другое, пишет Beam WRT туда сразу. Описание в конце 1-install.txt.
- В инструкции и на странице Слоты уточнено, что команды nvram для возврата из стока выполняются в заводской прошивке. В Beam WRT nvram нет, там слот переключает страница Слоты.

Обновление с 1.4.7 обычное, настройки не меняются. Ядро то же, что в 1.4.7, поэтому пакеты, которые вы ставили сами, остаются как есть.

Beam WRT 1.4.8. The router no longer reboots when the 5 GHz module firmware crashes during an MLO reconfiguration, and roamd and moving from another OpenWrt are new.

What was fixed

- If the 5 GHz module firmware crashed while hostapd was reconfiguring the MLO network with clients connected, for example after a Wi-Fi settings change, the ath12k driver used tables that had already been freed, the kernel crashed and the router rebooted. Now the firmware restarts and the router keeps running.
- After installing a package with a new protocol (GRE, L2TP, 6in4 and others), its interface did not come up until the network was restarted: the network learns its protocols only when it starts. LuCI now shows a Restart network button in the top bar with an explanation, and apk prints the same after the install.

What is new

- The Services, Add-ons page now has roamd, seamless Wi-Fi roaming: moving clients from 2.4 to 5 GHz, 802.11k/v/r and a network of several OpenWrt routers. It is built in the Beam WRT feed with two changes. It leaves the MLO network alone, because 802.11r on it crashed the 5 GHz module firmware. Updates come from the feed rather than its built-in check.
- The release archive has install-from-openwrt.sh for moving to Beam WRT from another OpenWrt with the factory bootloader. If the other slot holds the factory firmware, it switches the boot to it and erases nothing. If it holds something else, it writes Beam WRT there right away. See the end of 1-install-en.txt.
- The instruction and the Slots page now say that the nvram commands for coming back from stock run in the factory firmware. Beam WRT has no nvram, there the Slots page switches the slot.

Updating from 1.4.7 is unchanged, settings stay as they are. The kernel is the same as in 1.4.7, so the packages you added yourself stay as they are.

Beam WRT 1.4.8。MLO 重新配置期间 5 GHz 模块固件崩溃时路由器不再重启，新增 roamd 以及从其他 OpenWrt 迁移的方式。

修复内容

- 如果 5 GHz 模块固件恰好在 hostapd 重新配置有客户端连接的 MLO 网络时崩溃（例如修改 Wi-Fi 设置之后），ath12k 驱动会访问已经释放的表，内核崩溃，路由器重启。现在固件会重新启动，路由器继续正常工作。
- 安装带有新协议的软件包（GRE、L2TP、6in4 等）后，在重启网络之前该协议的接口无法启动：网络只在启动时识别协议。现在 LuCI 顶部栏会显示“重启网络”按钮并附说明，apk 安装后也会给出同样的提示。

新增内容

- 服务 → 附加组件 页面新增 roamd，即无缝 Wi-Fi 漫游：把客户端从 2.4 GHz 引导到 5 GHz、802.11k/v/r，以及由多台 OpenWrt 路由器组成的网络。它在 Beam WRT 软件源中编译，并做了两处修改。它不会改动 MLO 网络，因为在其上启用 802.11r 会导致 5 GHz 模块固件崩溃。更新来自软件源，而不是它自带的检查。
- 发布压缩包中新增 install-from-openwrt.sh，用于从使用原厂引导程序的其他 OpenWrt 迁移到 Beam WRT。如果另一个槽位里是原厂固件，它会把启动切换过去，不擦除任何东西；如果是其他内容，则直接把 Beam WRT 写入该槽位。说明见 1-install-zh.txt 末尾。
- 说明文档和 槽位 页面现在注明：从原厂固件切回所用的 nvram 命令需在原厂固件中执行。Beam WRT 没有 nvram，在 Beam WRT 中由 槽位 页面切换槽位。

从 1.4.7 更新的方法不变，设置保持不变。内核与 1.4.7 相同，因此您自己安装的软件包保持不变。
