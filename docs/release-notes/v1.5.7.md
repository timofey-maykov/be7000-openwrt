Beam WRT 1.5.7. Исправлены смена LAN-подсети через LuCI и кнопка возврата второго слота.

После изменения IPv4-адреса LAN LuCI подтверждает настройки по новому адресу и открывает его в браузере. Раньше подтверждение отправлялось на старый IP, из-за чего даже правильные настройки откатывались.

На подтверждение отводится 120 секунд с момента применения. Если старую вкладку закрыли, можно открыть новый адрес, войти в LuCI и нажать «Подтвердить новые настройки». В окне показано оставшееся время; повторный вход не продлевает отсчёт. Подтверждать изменения может применивший их пользователь с правом изменения настроек. Без подтверждения сохраняется автоматический откат.

Если компьютер остался в старой подсети, переподключитесь к Wi-Fi или обновите адрес по DHCP. Патч не меняет сетевые настройки компьютера. Отдельный патч для 1.5.6 на эту версию ставить не нужно.

Кнопка «Вернуть второй слот» больше не остаётся выключенной, когда данных мало и возврат разрешён. Ограничение по размеру `/overlay` сохраняется: данные должны помещаться на отдельном разделе данных.

Обновление обычное, с сохранением настроек и пакетов. Проверены установка и откат отдельного патча на файлах 1.5.6, браузерные сценарии переподключения и повторного входа, а также проверки подтверждения и таймера. Смена LAN-подсети с этим исправлением на физическом BE7000 пока не проверялась.

Beam WRT 1.5.7. Fixes LAN subnet changes in LuCI and the second-slot recovery button.

After the LAN IPv4 address changes, LuCI confirms the settings at the new address and opens it in the browser. Previously confirmation went to the old IP, causing even valid changes to roll back.

Confirmation has a 120-second window from the start of the apply operation. If the original tab was closed, open the new address, log in and click "Confirm new settings". The dialog shows the remaining time; logging in does not restart the timer. Recovery confirmation requires the user who applied the changes and permission to modify settings. Unconfirmed changes are still rolled back automatically.

If the computer remains on the old subnet, reconnect to Wi-Fi or renew its DHCP lease. The patch does not change the computer's network settings. The separate hotfix for 1.5.6 is not needed on this version.

The "Give the second slot back" button no longer stays disabled when the data is small enough to allow recovery. The `/overlay` size check remains: the data must fit on the separate data partition.

Update normally, keeping settings and packages. Validation covers installing and removing the standalone hotfix on 1.5.6 files, browser reconnect and re-login scenarios, confirmation checks and the rollback timer. Changing the LAN subnet with this fix has not yet been tested on a physical BE7000.

Beam WRT 1.5.7。修复了 LuCI 更改 LAN 子网和收回第二个槽位按钮的问题。

更改 LAN IPv4 地址后，LuCI 会向新地址发送确认，再在浏览器中打开新地址。以前确认仍然发往旧 IP，即使设置正确也会被回滚。

从开始应用设置起，有 120 秒时间进行确认。如果关闭了原标签页，可以打开新地址，登录 LuCI 并点击“确认新设置”。窗口显示剩余时间，重新登录不会重置倒计时。只有应用更改的用户且具有修改设置权限时才能确认。未确认的更改仍然会自动回滚。

如果电脑仍在旧子网中，请重新连接 Wi-Fi 或续租 DHCP 地址。补丁不会更改电脑的网络设置。本版本已包含修复，不需要再安装 1.5.6 的独立补丁。

当数据量足够小、允许收回槽位时，“收回第二个槽位”按钮不再一直处于禁用状态。`/overlay` 容量检查仍然保留：数据必须能放回独立数据分区。

更新方法不变，可保留设置和软件包。已验证独立补丁在 1.5.6 文件上的安装和撤销、浏览器重新连接及重新登录场景、确认权限检查和回滚计时。尚未在实体 BE7000 上验证此修复下的 LAN 子网更改。
