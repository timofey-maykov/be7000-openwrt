Beam WRT 1.4.9. Support for routers from the latest batches, Steer from Zapret Manager, a BE7000 as a roamd node.

What changed

- The firmware installs and runs on routers from the latest batches, where it did not boot before. Routers that already run it see no change.
- Steer installs from Zapret Manager. Zapret Manager is updated to 3.97.
- roamd: a BE7000 can join as a node a network that another BE7000 on Beam WRT manages. A node is reset to factory settings when it joins.
- The feed has a Status, Modem page for USB modems: signal, cell, bands, mode selection and an AT command console. Install it with apk add luci-app-beam-modem.

Updating is the usual one, settings and packages are kept, nothing needs reinstalling.

If your router is from a latest batch where the firmware did not install before, install from stock with 1-install-en.txt as usual and tell us in the thread how it went.

Beam WRT 1.4.9。支持最新批次的路由器，Steer 可从 Zapret Manager 安装，BE7000 可作为 roamd 节点。

更新内容

- 固件现在可以安装并运行在最新批次的路由器上，此前在这些路由器上无法启动。已经在运行的路由器没有任何变化。
- Steer 可以从 Zapret Manager 安装。Zapret Manager 已更新到 3.97。
- roamd：BE7000 可以作为节点加入由另一台运行 Beam WRT 的 BE7000 管理的网络。加入时节点会恢复出厂设置。
- 软件源中新增 状态 → 调制解调器 页面，用于 USB 调制解调器：信号、小区、频段、模式选择和 AT 命令控制台。用 apk add luci-app-beam-modem 安装。

更新方法不变，设置和软件包都会保留，无需重新安装。

如果您的路由器属于此前无法安装固件的最新批次，请照常按 1-install-zh.txt 从原厂固件安装，并在讨论帖中告诉我们结果。
