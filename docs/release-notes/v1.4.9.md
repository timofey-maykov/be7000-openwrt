Beam WRT 1.4.9. Прошивка встаёт на новые платы с флешкой ESMT, Steer ставится из Zapret Manager, BE7000 может быть узлом roamd.

Что изменилось

- На новых платах BE7000 стоит другая флешка, ESMT F50D1G41LB, и на них не загружалась ни одна сборка на основе OpenWrt, в том числе Beam WRT. Сток выбирает силу коррекции ошибок (ECC) по модели флешки: на привычной GigaDevice 8 бит, на ESMT 4 бита. Beam WRT всегда ставил 8, и на ESMT ядро не могло прочитать свою флешку. Теперь ECC берётся из той же таблицы, что в стоке, для всех 17 моделей флешек, которые знает сток. На уже работающих роутерах ничего не меняется, обновление обычное. Модель флешки и выбранный ECC видны в системном журнале строкой SPI NAND.
- Steer ставится из Zapret Manager. Раньше установка обрывалась с ошибкой: Zapret Manager качает Steer из релизов его автора, а там нет сборки под процессор BE7000. Теперь Steer собирается в фиде Beam WRT из исходников автора и обновляется вместе с его релизами, а Zapret Manager обновлён до 3.97 и берёт Steer оттуда. Если строка фида Steer была добавлена руками с ошибкой, он её исправит.
- roamd: BE7000 можно подключить узлом к сети, которой управляет другой BE7000 с Beam WRT. Раньше контроллер отказывал с сообщением, что репозиторий пакетов недоступен. При захвате узел сбрасывается к заводским настройкам.
- В фиде появилась страница Статус, Модем для USB-модемов через ModemManager: сигнал с графиком, сота, диапазон и частота, агрегация несущих, выбор режима и диапазонов, консоль AT-команд. Ставится командой apk add luci-app-beam-modem. Для данных о сотах у модемов с MBIM нужен ещё пакет qmi-utils, он тоже в фиде.

Обновление с 1.4.8 и более ранних версий обычное, настройки и пакеты сохраняются. Ядро для модулей то же, что в 1.4.7 и 1.4.8, пакеты переустанавливать не нужно.

Платы с флешкой ESMT. Установка из стока по инструкции 1-install.txt, как обычно. Сам выбор ECC проверен на такой плате пробной сборкой с той же настройкой, сборку 1.4.9 на ней ещё никто не запускал. Если у вас такая плата, после установки пришлите строку из журнала: dmesg | grep "SPI NAND". Подключение BE7000 узлом roamd на двух роутерах тоже ещё не проверялось.

Beam WRT 1.4.9. The firmware installs on newer boards with the ESMT flash, Steer installs from Zapret Manager, and a BE7000 can be a roamd node.

What changed

- Newer BE7000 boards carry a different flash, the ESMT F50D1G41LB, and no OpenWrt based build booted on them, Beam WRT included. Stock picks the error correction (ECC) strength by flash model: 8 bits on the usual GigaDevice part, 4 bits on the ESMT one. Beam WRT always used 8, so on ESMT the kernel could not read its own flash. The ECC now comes from the same table as in stock, for all 17 flash models stock knows. Routers that work today keep their setting, the update is the usual one. The flash model and the ECC in use show up in the system log as an SPI NAND line.
- Steer installs from Zapret Manager. Before, the install stopped with an error: Zapret Manager downloads Steer from its author's releases, which have no build for the BE7000 CPU. Steer is now built in the Beam WRT feed from the author's sources and follows his releases, and Zapret Manager is updated to 3.97 and takes Steer from there. A Steer feed line added by hand with a mistake gets fixed.
- roamd: a BE7000 can join as a node a network that another BE7000 on Beam WRT manages. Before, the controller refused, saying the package repository was unreachable. A captured node is reset to factory settings.
- The feed has a Status, Modem page for USB modems through ModemManager: signal with a graph, cell, band and frequency, carrier aggregation, mode and band selection, and an AT command console. Install it with apk add luci-app-beam-modem. Cell data on MBIM modems also needs qmi-utils, which is in the feed too.

Updating from 1.4.8 and older versions is the usual one, settings and packages are kept. The kernel for modules is the same as in 1.4.7 and 1.4.8, packages need no reinstall.

Boards with the ESMT flash. Install from stock with 1-install-en.txt as usual. The ECC choice itself was checked on such a board with a test build that used the same setting; nobody has run the 1.4.9 build there yet. If you have such a board, please send the log line after installing: dmesg | grep "SPI NAND". Joining a BE7000 as a roamd node has not been tried on two routers yet either.

Beam WRT 1.4.9。固件可以安装到配备 ESMT 闪存的较新主板上，Steer 可以从 Zapret Manager 安装，BE7000 可以作为 roamd 节点。

更新内容

- 较新的 BE7000 主板使用另一种闪存 ESMT F50D1G41LB，在这些主板上任何基于 OpenWrt 的固件都无法启动，Beam WRT 也不例外。原厂固件按闪存型号选择纠错（ECC）强度：常见的 GigaDevice 为 8 位，ESMT 为 4 位。Beam WRT 一直使用 8 位，因此在 ESMT 上内核读不了自己的闪存。现在 ECC 取自与原厂固件相同的表，覆盖原厂已知的全部 17 种闪存型号。已经在运行的路由器设置不变，按常规更新即可。闪存型号和所用 ECC 会以 SPI NAND 一行显示在系统日志中。
- Steer 可以从 Zapret Manager 安装了。此前安装会报错中断：Zapret Manager 从作者的发布页下载 Steer，而那里没有适用于 BE7000 处理器的版本。现在 Steer 在 Beam WRT 软件源中根据作者的源码编译并跟随其发布更新，Zapret Manager 已更新到 3.97 并从那里获取 Steer。手动添加且有错误的 Steer 软件源行会被自动修正。
- roamd：BE7000 可以作为节点加入由另一台运行 Beam WRT 的 BE7000 管理的网络。此前控制器会以软件包仓库不可用为由拒绝。被接管的节点会恢复出厂设置。
- 软件源中新增 状态 → 调制解调器 页面，用于通过 ModemManager 工作的 USB 调制解调器：带图表的信号、小区、频段和频率、载波聚合、模式和频段选择，以及 AT 命令控制台。用 apk add luci-app-beam-modem 安装。MBIM 调制解调器的小区数据还需要 qmi-utils，它同样在软件源中。

从 1.4.8 及更早版本更新的方法不变，设置和软件包都会保留。模块所用的内核与 1.4.7 和 1.4.8 相同，无需重新安装软件包。

配备 ESMT 闪存的主板：按 1-install-zh.txt 从原厂固件安装即可。ECC 的选择已在这种主板上用相同设置的测试固件验证过，但 1.4.9 本身还没有人在上面运行过。如果您有这种主板，安装后请发送日志中的这一行：dmesg | grep "SPI NAND"。BE7000 作为 roamd 节点加入网络也尚未在两台路由器上测试过。
