Beam WRT 1.5.1. Роутер не уходит на сток из-за умирающей флешки, сторонние пакеты ставятся без ошибки версии.

Что изменилось

- Если флешка с extroot начинает умирать, роутер больше не уходит на заводскую прошивку. Раньше каждая загрузка с такой флешкой обрывалась, и после шести попыток загрузчик переключался на сток. Теперь, если прошлая загрузка не дошла до конца, роутер стартует без USB на встроенной памяти и остаётся доступен.
- Скрипты установки сторонних пакетов больше не ругаются на версию. Для них прошивка теперь OpenWrt 25.12.6, а Beam WRT и её номер видны в описании, баннере и LuCI.
- Страница обновления качает образ в фоне и показывает, сколько скачано, а сам образ берёт с зеркала на GitHub Pages. Раньше на медленной связи с GitHub окно крутилось бесконечно.
- roamd: узел на BE7000 с Beam WRT получает roamd от контроллера, ставить его на узел руками не нужно.
- Баннер при входе по SSH снова показывает версию и благодарности.

Обновление обычное, настройки и пакеты сохраняются.

Спасибо Danis11, который нашёл обе проблемы.

Beam WRT 1.5.1. A dying flash drive no longer sends the router to stock, third-party packages install without a version error.

What changed

- When a flash drive with extroot starts dying, the router no longer ends up on the stock firmware. Before, every boot with such a drive broke off, and after six tries the bootloader switched to stock. Now, if the previous boot did not finish, the router starts without USB on its built-in storage and stays reachable.
- Install scripts of third-party packages no longer complain about the version. To them the firmware is now OpenWrt 25.12.6, while Beam WRT and its number show in the description, the banner and LuCI.
- The update page downloads the image in the background, shows how much is in, and takes the image from a mirror on GitHub Pages. Before, on a slow link to GitHub the dialog spun forever.
- roamd: a BE7000 node with Beam WRT gets roamd from the controller, there is no need to install it on the node by hand.
- The SSH login banner shows the version and the thanks again.

Updating is the usual one, settings and packages are kept.

Thanks to Danis11, who found both problems.

Beam WRT 1.5.1。U 盘损坏不再让路由器切回原厂固件，第三方软件包安装时不再报版本错误。

更新内容

- 当 extroot 所在的 U 盘开始损坏时，路由器不再切回原厂固件。以前每次带着这样的 U 盘启动都会中断，尝试六次后引导程序就切换到原厂固件。现在如果上一次启动没有完成，路由器会不加载 USB、使用内置存储启动，保持可以访问。
- 第三方软件包的安装脚本不再报版本不支持。对它们来说固件现在是 OpenWrt 25.12.6，而 Beam WRT 及其版本号显示在描述、登录横幅和 LuCI 中。
- 更新页面在后台下载镜像并显示已下载的大小，镜像从 GitHub Pages 上的镜像站获取。以前在与 GitHub 连接很慢时对话框会一直转圈。
- roamd：运行 Beam WRT 的 BE7000 节点会从控制器获得 roamd，不需要在节点上手动安装。
- SSH 登录横幅又会显示版本和致谢了。

更新方法不变，设置和软件包都会保留。

感谢 Danis11 发现了这两个问题。
