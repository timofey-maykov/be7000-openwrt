Патч смены LAN-подсети через LuCI для Beam WRT 1.5.6

После смены IPv4-адреса LAN интерфейс теперь подтверждает настройки по новому адресу и переходит на него. Защита с автоматическим откатом остаётся включённой. Новый IP и подсказка о DHCP видны во время применения.

Патч предназначен только для Beam WRT 1.5.6. Установщик сверяет версию прошивки и контрольные суммы файлов LuCI. Если они отличаются от релизных, установка прекращается без изменений. На другие сборки OpenWrt этот архив ставить не нужно.

Установка

1. Скачайте приложенный be7000-luci-lan-hotfix-v1.5.6-r1.tar.gz на компьютер.
2. Через WinSCP или scp загрузите архив в /tmp на роутере. Для scp на современных Linux/macOS используйте ключ -O. Подставьте текущий адрес своего роутера:

scp -O be7000-luci-lan-hotfix-v1.5.6-r1.tar.gz root@192.168.31.1:/tmp/

3. Подключитесь к роутеру по SSH:

ssh root@192.168.31.1

4. Распакуйте архив и проверьте совместимость:

cd /tmp
tar -xzf be7000-luci-lan-hotfix-v1.5.6-r1.tar.gz
cd be7000-luci-lan-hotfix-v1.5.6-r1
sh install.sh check

При успешной проверке будет строка Compatible. Если появились ERROR или FAILED, остановитесь и пришлите вывод. Принудительно обходить проверку не нужно.

5. Установите исправление:

sh install.sh apply

Установщик сохранит исходные файлы в /root/be7000-luci-lan-hotfix-v1, заменит файлы LuCI и перезапустит только веб-интерфейс. Перепрошивка и перезагрузка роутера не нужны; настройки сети патч не меняет. При ошибке установки исходные файлы восстанавливаются автоматически.

6. Закройте старые вкладки LuCI, откройте интерфейс заново и обновите страницу с очисткой кэша: Ctrl+F5, на macOS — Cmd+Shift+R.

Проверка смены подсети

Например, задайте LAN адрес 10.232.70.1 с маской 255.255.255.0 и нажмите «Сохранить и применить», затем подтвердите применение с проверкой. 10.232.70.0/24 — адрес подсети; адрес самого роутера в этом примере — 10.232.70.1.

Если компьютер сохранил адрес из старой подсети, сразу переподключитесь к Wi-Fi или переподключите сетевой кабель, чтобы получить новый адрес по DHCP. При ручных настройках задайте компьютеру свободный адрес из новой подсети. Сам патч не может изменить сетевые настройки компьютера.

После восстановления связи LuCI подтвердит настройки и перейдёт на новый IP. По умолчанию на подтверждение отводится 90 секунд. Если за это время связь не восстановится, роутер вернёт прежние настройки. После отката компьютеру тоже может понадобиться обновить адрес по DHCP.

Как удалить патч

В SSH выполните:

sh /root/be7000-luci-lan-hotfix-v1/hotfix.sh rollback

Будут восстановлены исходные файлы LuCI, после чего нужно снова обновить страницу с очисткой кэша. Настройки сети при удалении патча не меняются.

Исправление также войдёт в следующий релиз. Патч проверен на файлах опубликованной 1.5.6, в тестах установки/отката и в браузерном сценарии переподключения. Проверка смены подсети на физическом BE7000 пока не проводилась.
